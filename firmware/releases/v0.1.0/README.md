# Work Louder Micro Codex v0.1.0

First public release of the tested Candidate 1 firmware.

## Compatibility

- QMK target: `work_louder/micro`
- MCU: ATmega32U4
- Bootloader: Atmel DFU
- VID:PID: `574C:E6E3`
