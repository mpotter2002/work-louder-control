# Security and Hardware Safety

For software security reports, open a private GitHub security advisory for this
repository.

For hardware compatibility concerns, open an issue without flashing first.
Include the board name, MCU, VID:PID, and bootloader if known.

Never attach proprietary firmware dumps, access tokens, private Codex session
files, or personal VIA exports to a public issue.

This project cannot replace or recover the read-protected factory firmware.
